# Digital Profile & Contact Card

A minimalist, monochrome personal profile and digital contact card for **Amudalapalli Venkateswara Rao (Venkatesh)**. Designed for instant mobile scanning via QR codes on keychains, cards, or NFC tags.

## 🚀 Features
- **Minimalist Monochrome Aesthetic**: Deep onyx background with floating blurred gradient orbs and frosted glass card.
- **Mobile-First & Fully Symmetrical**: Square photo frame aligned symmetrically with contact details and action buttons.
- **One-Tap Actions**:
  - 📞 **Call Direct**
  - 💬 **WhatsApp Chat**
  - ✉️ **Send Email**
- **Zero Build Tools Required**: Pure HTML5, CSS3, and lightweight Vanilla JavaScript.

## 📁 Project Structure
```
├── index.html       # Webpage structure & semantic markup
├── style.css        # Monochrome styling, glassmorphism & ambient gradient orbs
├── app.js           # Interactive parallax effects
├── Venkatesh.jpg    # Profile portrait photo
└── README.md        # Project documentation
```
